# Belhrach School — Student Portal

واجهة التلميذ الأولية: الاسم، اللقب، القسم، وإرسال طلب التفعيل. تحفظ الواجهة رمز متابعة عشوائياً في المتصفح حتى يستطيع التلميذ معرفة قرار الإدارة.

## النشر
1. ارفع محتويات هذا المجلد إلى مستودع GitHub مستقل.
2. في Cloudflare Pages أنشئ مشروعاً واربطه بالمستودع.
3. اختر Framework preset: **None**، وBuild command فارغ، وOutput directory `/`.
4. بعد نشر Worker، افتح `config.js` وضع رابط السيرفر في `API_BASE`.
5. أعد نشر Pages.

لا تضع أي كلمة مرور أو سر إداري في هذا المشروع الأمامي.
